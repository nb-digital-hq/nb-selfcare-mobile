# ADR-017: Una sola persona

> **Estado:** Aceptado.

**Fecha:** 2026-11-18

## Contexto

Las funciones sociales (amigos, clasificaciones, publicaciones) fomentan la comparación y exigen servidores.

## Decisión

Cada teléfono pertenece a una persona. No hay perfiles múltiples, ni botones para publicar en redes, ni
comparación con otros. Lo único que se comparte es lo que la persona decide: la copia de seguridad o el informe PDF.

## Consecuencias

Ningún dato depende de otra persona ni de un servidor.
