# Perfil y ajustes

> **Estado:** Implementado.

## Perfil (círculo de arriba a la derecha)

Datos personales, metas y gasto diario (se ajusta solo cada 14 días o a mano), fase de dieta y tipo de dieta, ciclo
menstrual, descubrimientos entre tus hábitos, tu protocolo semanal y el **informe PDF** para tu médico.

## Ajustes (rueda del perfil)

| Apartado | Qué contiene |
|---|---|
| Idioma | El del teléfono, español, inglés o portugués |
| Ícono de la app (Android) | El logotipo con el color de cualquier tema |
| Acerca de y actualizaciones | Versión y "Buscar actualizaciones" (Android) |
| Apariencia | 24 temas, incluidos cuatro de aspecto papel |
| Recordatorios (Android) | Pesaje, agua, ventana de comidas, diario, cinta, desconectar, suelo pélvico, descanso visual y pausas activas; avisos discretos y tu hora de dormir |
| Tus equipos | Báscula Mi Scale 2, Health Connect (Android) y aparatos de signos vitales |
| Secciones | Ayuno, ciclo menstrual y apartados de Cuidado |
| Permisos (Android) | Estado de cada permiso y acceso a los ajustes del teléfono |
| Tus datos | Crear y compartir una copia de seguridad, o restaurar una |
| Líneas de apoyo | Números para hablar con alguien |

## Tu ordenador

Vincula NB SelfCare de escritorio para revisar en el ordenador lo que registras aquí. En el ordenador abre
Ajustes > Teléfono, permite la conexión y genera un código; en el teléfono pulsa **Vincular con el ordenador** y
escanéalo, o pulsa **Usar código en texto** y pega el código que muestra el ordenador. Los datos viajan cifrados por tu red local, sin nube ni cuentas. La sincronización ocurre al abrir la
app, cada pocos minutos mientras la usas y poco después de cada registro. Si el mismo dato cambió en los dos
equipos, lo decides en el ordenador. **Desvincular** detiene la conexión y conserva los datos en ambos.
