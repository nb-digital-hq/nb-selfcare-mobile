# Convención de commits

> **Estado:** Aplicable.

```bash
git commit -s -m "fix(fasting): conservar la hora de inicio al reabrir la app"
```

* Conventional Commits: `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `build`, `ci`, `chore`, con
  ámbito opcional.
* Asunto y cuerpo en español. El cuerpo explica por qué y qué se verificó.
* `-s` es obligatorio: declaración de origen (DCO).
