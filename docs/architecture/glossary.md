# Glosario

> **Estado:** Aplicable.

| Término | Significado |
|---|---|
| **BIA** | Bioimpedancia: estimación de la composición corporal a partir de la resistencia eléctrica entre los pies |
| **EMA** | Media móvil exponencial; aquí, el peso tendencia (α = 0,1) |
| **Falsa subida** | Aumento de peso de 0,4 kg o más explicado por agua (sal, glucógeno, fase lútea, creatina), no por grasa |
| **TDEE** | Gasto energético diario total; aquí se recalcula cada 14 días con la tendencia y lo comido |
| **MET** | Equivalente metabólico de una actividad; el gasto neto descuenta 1 MET de reposo |
| **NEAT** | Gasto de la actividad que no es ejercicio, medido aquí con los pasos |
| **NOVA** | Clasificación de los alimentos por su grado de procesamiento (grupos 1 a 4) |
| **FTS5** | Índice de búsqueda de texto completo de SQLite, sin tildes |
| **OMS-5** | Índice de bienestar de la OMS: cinco preguntas, puntuación de 0 a 100 |
| **Tema de papel** | Tema con `isFlat`: sin sombras ni animaciones y con filetes de 1,5 px |
| **Equipos declarados** | Aparatos que la persona dice tener (báscula, tensiómetro, glucómetro, oxímetro, termómetro) |
| **Libre** | Apartado de contadores para dejar hábitos |
| **Nibi** | El dragón que acompaña a la persona; su nombre se puede cambiar |
| **Escudo de racha** | Objeto de la tienda que protege la racha un día sin actividad |
| **Puerta de red** | `lib/core/network/`, el único lugar donde se construye un cliente HTTP |
